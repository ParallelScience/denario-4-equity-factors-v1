The observed failure of the Characteristic-Sorted portfolio to capture the Momentum (WML) factor is directly attributable to the dataset's Data Generating Process (DGP). The description states that "all stocks have WML loading of 0.3," meaning there is zero cross-sectional variation in the true momentum loading. Consequently, sorting stocks into quintiles based on lagged returns (as per the research plan) effectively sorts on idiosyncratic noise ($\sigma = 3.5\%$) rather than a structural characteristic, rendering the sorting methodology structurally misspecified for this factor.
